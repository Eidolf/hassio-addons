# Eidolf's Home Assistant Add-ons

Welcome to Eidolf's Home Assistant Add-on repository.

## Add-ons in this repository

### 🦅 [ER-Adlernest](er_adlernest/)
**"Your Eagle Eye for Home Assistant Surveillance"**
A modern CCTV live viewer, archive manager, and NAS recording explorer for Home Assistant. Features multi-camera grid layouts, Reolink optimization, automated Samba/CIFS archive scanning, and video playback.

### 📍 [Google Find My Tools](google_find_my_tools/)
Experimental tools for Google's Find My Device Network enabled in Docker with noVNC.

---

## Installation

1. Navigate to the **Add-on Store** in your Home Assistant instance.
2. Click the three dots (top right) -> **Repositories**.
3. Add this repository URL:
   ```
   https://github.com/Eidolf/hassio-addons
   ```
4. Find **ER-Adlernest** in the list, click **Install**, and enjoy!
